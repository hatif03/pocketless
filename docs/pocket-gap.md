# Pocket features → Pocketless

Pocket’s jobs stay. The recorder UI, the puck, and a call we host do not.

| Pocket | Hackathon | After submit |
|--------|-----------|--------------|
| One-button capture | Paste **Google Meet** URL → bot joins | Zoom + Teams adapters; companion |
| Transcript | Episode on a person | Export |
| Summary | Relationship brief via Gateway | Templates / regen |
| Action items | Promises, creatable live | Task app OAuth |
| Ask Pocket | Talk to Pocketless | Corpus RAG |
| Speakers | Participant events + AAI `speaker_labels` | Enroll “you” |
| Calendar / email | Mock in-call tools | Real OAuth |
| Mind map | Topics list if time | Graph |
| Hardware / contact-mic | Out of scope | Never the brand |
| Unlimited free STT | Do not copy | Meter hours |

Thesis: **stay with the human**. Pocketless joins *their* Meet, silent until addressed, memory on the relationship.
